# Shark Tank Startup Investment Analysis 📊

## 📌 Project Overview

This project analyzes startup investment and funding patterns using a Shark Tank startup dataset. The analysis focuses on industry-wise investment, shark-wise investment trends, deal acceptance, average deal amounts, top-funded startups, and the difference between requested and actual deal amounts.

The project combines **Python-based data analysis** with **Excel and Microsoft Power BI dashboards** to transform raw startup data into meaningful insights.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze startup investment and funding trends
- Identify industries receiving higher levels of investment
- Analyze investment patterns of individual sharks
- Study startup deal acceptance rates
- Identify the top-funded startups
- Compare requested investment amounts with actual deal amounts
- Calculate key investment and deal metrics
- Present findings through interactive dashboards



## 📂 Dataset

The dataset contains information about **290 startups** with **64 attributes**, including startup details, industry categories, investment information, investor participation, and deal-related information.

## 📊 Key Analysis & Findings

### Industry-wise Investment

The **Food** industry recorded the highest total investment in the analyzed dataset, followed by **Beauty/Fashion** and **Medical/Health**.

### Shark-wise Investment

Among the sharks represented in the dataset, **Aman** had the highest cumulative investment amount.

### Deal Acceptance

Out of 290 startups:

- **175 deals were accepted**
- **115 deals were not accepted**

This results in an overall deal acceptance rate of **60.34%**.

### Top-Funded Startups

The analysis identifies the startups receiving the highest recorded investment amounts, including:

- Pharmallama
- UnStop
- MeduLance
- Trunome
- Stage
- Snitch
- Portl
- AasVidyalaya
- MindPeers
- Annie

### Requested vs Actual Deal Amount

The project also compares the amount requested by startups with the actual deal amount recorded in the dataset. This helps identify cases where the final investment differed from the original request.
